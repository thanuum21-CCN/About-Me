# Hi, I'm Thanu 👋

I am a **Computer Science Graduate** transitioning into **Computational and Cognitive Neuroscience**. I leverage my background in algorithms, numerical computing, and data structures to model neural circuit dynamics, analyze electrophysiological and neuroimaging data, and investigate computational theories of cognition.


### 🧠 Core Research Interests & Focus Areas
- 🔬 **Neural Dynamics:** Single-neuron biophysics (Hodgkin-Huxley, Leaky Integrate-and-Fire) and spiking network models (E/I balance, oscillations).
- 🧩 **Cognitive Modeling:** Reinforcement learning models of decision making, memory networks, and attractor network models of working memory.
- 📊 **Neural Data Analysis:** Processing and analyzing spike trains, local field potentials (LFPs), and large-scale neuroimaging datasets.


### 🛠️ Tech Stack & Toolkit

- **Comp Neuro & Simulation:** Brian2, NEURON, Nest
- **Data Science & Signal Processing:** NumPy, SciPy, Pandas, MNE-Python, Scikit-Learn
- **Software Engineering:** Git, Linux, Docker, Unit Testing (`pytest`)
